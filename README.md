# Sofia-Lark

Design work for [sofialark.com](https://sofialark.com).

- [`product-page/`](product-page/): product page analysis ([ANALYSIS.md](product-page/ANALYSIS.md)) and a working high-end product page prototype ([index.html](product-page/index.html)), built with real Calypso data from the store.
- [`theme/`](theme/): the same layout as the default product template for the Impulse theme. It works for every product as it is, reading size, material and promises from the descriptions. Details are in [theme/README.md](theme/README.md). It can be previewed on the real store, on an unpublished copy of the theme: [preview link](https://sofialark.com/products/earrings-calypso?preview_theme_id=209273651545).
